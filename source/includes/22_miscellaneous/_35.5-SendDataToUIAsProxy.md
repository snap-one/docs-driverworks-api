## SendDataToUIAsProxy

Function to send data to the UI as one of the driver's own proxies, rather than as the protocol driver. This API should not be invoked during OnDriverInit. Also, see [SendDataToUI][1].


###### Available from 4.4.0


### Signature

`C4:SendDataToUIAsProxy(idBinding, strXML)`


| Parameter | Description |
| --- | --- |
| num | Binding ID. |
| str | XML string to send. |


### Returns

| Value | Description |
| --- | --- |
| bool | True when the data was sent. False when the XML is invalid or the binding isn't one of the driver's proxy bindings. |


### Usage Note

The xml must be properly formatted and escaped for the function to succeed. Only the driver's own proxies, as returned by [GetProxyDevices][2], are allowed; for any other device nothing is sent and an error is logged.


### Example

Sending XML string as the proxy on binding 5001:

`C4:SendDataToUIAsProxy(5001, "<myxml>xml data to be sent</myxml>")`
